# Birthday Wish Website

A simple React + TypeScript birthday wishing website built with Vite.

## Available Scripts

- `npm install` — install dependencies
- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build

## Project Structure

- `src/App.tsx` — birthday wish component and UI
- `src/main.tsx` — application entry point
- `src/styles.css` — page styles
- `index.html` — app shell

## Next Steps

Customize the wishes, add images, and update the message content for your birthday greeting.
